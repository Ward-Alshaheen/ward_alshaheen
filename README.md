## 🚀 Running Locally

The project is zero-dependency and requires no build step:

### Option 1: Direct File Opening
Double-click `index.html` to open it in your favorite browser.

### Option 2: Lightweight Python Server
```bash
# In the project directory
python -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.

### Option 3: Node / npx
```bash
npx serve .
```

## 🌐 Deploying to GitHub Pages

1. Go to repository **Settings** on GitHub.
2. Under **Code and automation**, click **Pages**.
3. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
4. Select `main` branch and `/ (root)` folder, then click **Save**.
5. Your portfolio will be live at:
   `https://ward-alshaheen.github.io/ward_alshaheen/`
